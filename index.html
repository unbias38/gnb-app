gnb：Gemini Notebook 筆記本建立工具

gnb 是一支在個人電腦上執行的命令列小工具，透過 Gemini Notebook API 建立筆記本，並把網頁、YouTube 影片與文字加入為來源。

這是個人自用工具，不對外提供服務，沒有伺服器，也沒有帳號系統。

使用的 Google 權限

工具只要求一項權限：讀寫使用者自己的 Gemini Notebook 筆記本與來源（https://www.googleapis.com/auth/notebook）。

隱私權政策

gnb is a personal command-line tool that creates Gemini Notebook notebooks and adds sources through the Gemini Notebook API. It is not a public service.
