隱私權政策

最後更新：2026-11-23

蒐集的資料

gnb 不蒐集任何個人資料。工具完全在使用者自己的電腦上執行，沒有後端伺服器，也沒有分析或追蹤程式。

Google 帳戶資料的使用

使用者以 Google 帳戶授權後，工具取得存取 Gemini Notebook 的權限，只用來做使用者下指令要求的事：建立筆記本、加入來源、列出筆記本與來源。

授權憑證只儲存在使用者自己的電腦上，不會傳送給開發者或任何第三方。工具只與 Google 的 API 端點通訊。

資料分享

不分享、不出售、不轉移任何資料。

撤銷授權

使用者可以隨時到 Google 帳戶的「第三方應用程式與服務」頁面移除這個工具的存取權，並刪除電腦上的憑證檔。

回首頁

gnb collects no personal data. It runs entirely on the user's own computer, stores OAuth credentials locally, and communicates only with Google API endpoints. Data is never shared, sold, or transferred.
